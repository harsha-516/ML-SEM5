# Sample raw data

CSV copies of the raw datasets so they can be opened in Excel. The full files are large and stay out of git (`data/raw/`, parquet format).

| File | What it is | Rows |
|---|---|---|
| usgs_catalog.csv | USGS earthquake catalogue (full) | 120,178 |
| gdacs_floods.csv | GDACS flood events (full) | 4,405 |
| basin_rain.csv | Rainfall by river basin (full) | 4,170 |
| himawari_features.csv | Himawari satellite cloud summaries for cyclones (full) | 3,946 |
| groundsource_region_sample.csv | Flood labels, first 20,000 of 1,154,790 rows | 20,000 |
| groundsource_2026_sample.csv | Groundsource flood events, first 2,000 rows | 2,000 |
| ibtracs_WP_recent5000.csv | West Pacific storm tracks, last 5,000 rows | 5,000 |
| ibtracs_NI_recent5000.csv | North Indian storm tracks, last 5,000 rows | 5,000 |
